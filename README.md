# OpenOCT

**OpenOCT** is an open-source initiative to make Optical Coherence Tomography (OCT) imaging accessible, affordable, and reproducible. We share software, hardware designs, and test tools so researchers, students, and makers can build, understand, and improve OCT systems.

## What is OCT?

Optical Coherence Tomography is a non-invasive imaging technique that uses low-coherence interferometry to produce high-resolution, cross-sectional images of scattering samples such as biological tissue. It is widely used in ophthalmology, dermatology, and materials research.

## Projects

| Repository | Description |
|------------|-------------|
| [OCTSharp](https://github.com/openoct/OCTSharp) | Open-source C# software for OCT acquisition and processing |
| [OCT-Spectrometer-800nm](https://github.com/openoct/OCT-Spectrometer-800nm) | Open-source, 3D-printable spectrometer designed for OCT imaging at 800 nm |
| [OCT_Phantom](https://github.com/openoct/OCT_Phantom) | Phantom fabrication and testing for OCT imaging |

## Goals

- Lower the cost and barrier to entry for building OCT systems
- Provide transparent, well-documented software and hardware designs
- Support validation and calibration with reproducible phantoms
- Build a community around open OCT research and education
